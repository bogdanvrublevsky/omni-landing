`<header>` - page-wide section on top of the page
`<aside>` - a side column of a page (can contain sections)
`<main>` - main pages content
`<section>` - a row in a column (can't contain another section)
`<article>` - an entry for a section
`<p>` - a row in a section
`<h1>` - the main heading of the page
`<h2>` - a header of a section
`<h3>` - a header for a section entry
`<address>` - contact info (contains multiple `<a>` for email, phone, telegram, etc.)
`<a>` - for anything clickable like email or telephone or download link
`<ul>+<li>` - for job entry metrics
`<dl>+<dt>+<dd>` - for languages (`<dt>` language, `<dd>` proficiency level)
`<dl>+<dt>` - for skills (same layout as languages, no `<dd>`/level)
`<small>` - a subheader of any header (can contain spans or smalls)
`<span>` - for parts of a text that should be styled or machine readable (with attributes or smthn)
`<span.icon>` - for inline icons element; spaces to the right
`<img.avatar>` - for big photo
