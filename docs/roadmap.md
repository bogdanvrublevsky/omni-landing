# Roadmap — anltx

Живой документ. Обновляется при сдвиге скоупа (см. `CLAUDE.md` → Documentation). Фазы ниже относятся к `main/` (сайт anltx) — единственной части монорепозитория в скоупе текущей инфраструктуры (см. `docs/adr/0006-monorepo-scope-boundary.md`). Параллельные направления монорепозитория — в отдельном разделе внизу.

## MVP (текущая фаза)

Цель: рабочий двуязычный сайт-визитка с лидогенерацией, деплоящийся автоматически.

- [ ] Astro-проект в `main/` (см. `docs/adr/0001-astro-ssg.md`) — на момент 2026-07 ещё не создан, текущая `main/index.html` — ручная HTML-версия, уже содержащая реальный контент лендинга (не пустышка).
- [ ] i18n-роутинг `/en/` `/ru/` с автоопределением + ручным переключателем (`docs/adr/0002-i18n-separate-paths.md`).
- [ ] Структура блога и раздела полезностей через Content Collections (`docs/adr/0003-content-collections.md`) — туториал по авторству создаётся вместе с этим пунктом (запрошено пользователем).
- [ ] Cookie consent banner, гейтящий GTM/GA4 до согласия (`CLAUDE.md` → Security).
- [ ] Техническая SEO-база: sitemap.xml, robots.txt, meta/OG, hreflang (GSC уже верифицирован).
- [ ] Форма лидогенерации → Cloudflare Worker (`*.workers.dev`, без миграции DNS) → Telegram (`docs/adr/0005-cloudflare-workers-lead-gen.md`).
- [ ] `deploy.yml` переписан под сборку Astro вместо прямого копирования файлов (`.claude/memory/deployment.md`) — отдельно решить, продолжает ли деплой публиковать `ttapp/` рядом с сайтом.
- [ ] Кастомная 404-страница (двуязычная).

## Beta

Цель: сайт наполнен реальным контентом, начинается работа над видимостью в поиске.

- Публикация первых статей блога и материалов раздела полезностей.
- Контентная SEO-стратегия (сознательно отложена с MVP, см. `docs/project-analysis.md` раздел 3.4).
- Возможное подключение Browser/Playwright MCP для автоматизации Lighthouse-проверок (см. `docs/mcp-evaluation.md`).
- Пересмотр процесса review при появлении второго участника команды (`CLAUDE.md` → Team уже допускает рост).

## Production / Scaling

Цель: сайт начинает приносить платящих клиентов, что меняет требования к инфраструктуре.

- Переход с GitHub Pages на полноценный хостинг — граница, явно зафиксированная как момент появления первых платящих клиентов (см. `.claude/memory/architecture.md`).
- Введение auth и серверного хранилища для платной части платформы.
- Проектирование архитектуры кастомной CMS (пересмотр `docs/adr/0004-custom-cms-direction.md` — новым ADR, не редактированием старого).
- Возможное подключение GitHub MCP при росте команды (см. `docs/mcp-evaluation.md`).
- Возможная миграция DNS на Cloudflare, если понадобится брендированный URL для Worker'а или CDN/WAF (осознанно отложено в `docs/adr/0005-cloudflare-workers-lead-gen.md`).

## Параллельные направления (вне скоупа `main/`)

Эти направления существуют в том же монорепозитории, упомянуты в README и/или в бизнес-контексте (`.claude/memory/business.md`), но **не входят** в текущую инфраструктуру и не имеют собственного discovery-интервью на момент 2026-07:

| Направление | Статус на 2026-07 | Примечание |
|---|---|---|
| `lwtms` (light-weight tag management system) | только упоминание в README, кода нет | конкретное содержание "полноценной аналитической платформы" из бизнес-целей |
| `sstms` (server-side TMS) | только упоминание в README, кода нет | см. выше |
| `dlext` (browser extension, инспекция data layer) | код есть (`manifest.json`, background/content scripts) | не деплоится сейчас |
| `ttapp` (helper для настольных RPG) | код есть, деплоится вместе с `main/` на GH Pages | известный security-инцидент устранён (`.claude/memory/security.md`), полноценная модель секретов не построена — вне скоупа |
| `sgame` (веб-игра) | только README | |
| `treev` (визуализация деревьев) | только README | |
| Кастомная CMS | направление подтверждено, архитектура не спроектирована | `docs/adr/0004-custom-cms-direction.md` |

Активация любого из этих направлений как задачи — отдельная сессия со своим Stage 1 (discovery), не расширение текущей инфраструктуры `main/` задним числом (см. `docs/adr/0006-monorepo-scope-boundary.md`).
