# 0006 — Границы скоупа инфраструктуры внутри существующего монорепозитория

- **Статус:** принято
- **Дата:** 2026-07-21

## Контекст

При подключении к существующему репозиторию `bogdanvrublevsky/anltx.xyz` выяснилось, что это монорепозиторий, а не изолированный проект под сайт anltx. Ветка `main` содержит `main/` (сайт, обсуждавшийся в интервью), а также `dlext/` (browser extension), `ttapp/` (helper для настольных RPG, с собственным auth), `sgame/` и `treev/` (только README, кода нет). README репозитория описывает более широкое видение с поддоменами `lwtms.anltx.xyz` и `sstms.anltx.xyz`, не раскрытое в исходном интервью.

## Проблема

Нужно решить, охватывает ли Claude Code инфраструктура (CLAUDE.md, memory, skills, hooks, subagents), проектируемая сейчас, весь монорепозиторий или только сайт anltx — от этого зависит объём и структура всей последующей работы.

## Варианты

1. **Весь монорепозиторий.** Требует полноценного discovery по каждому проекту (`dlext`, `ttapp`, `sgame`, `treev`, будущие `lwtms`/`sstms`) — многократно увеличивает объём интервью и рискует размыть фокус инфраструктуры, спроектированной для контентного сайта, нерелевантными для browser extension или Node-приложения правилами.
2. **Только `main/`.** Инфраструктура проектируется под то, что реально обсуждалось и понятно по требованиям. Остальные проекты остаются как есть, без изменений, до отдельного явного запроса.

## Принятое решение

Только `main/`. `CLAUDE.md`, `.claude/memory/`, будущие Skills/Hooks/Subagents ограничены сайтом anltx и общими корневыми файлами (`.gitignore`, `.github/workflows/`). `dlext/`, `ttapp/`, `sgame/`, `treev/`, а также будущие `lwtms/sstms` зафиксированы как отдельные направления в `docs/roadmap.md`, вне текущего скоупа.

## Последствия

- `CLAUDE.md` содержит явный раздел Scope, обязывающий останавливаться и уточнять у пользователя при любой задаче, затрагивающей файлы вне `main/`/`.claude/`/`docs/`/корневых конфигов.
- Обнаруженный в `ttapp/data/users.json` инцидент безопасности (см. [security.md](../../.claude/memory/security.md)) был устранён немедленно, несмотря на то что `ttapp` вне скоупа — публичная экспозиция секрета требует исправления независимо от границ скоупа инфраструктуры.
- Если позже потребуется распространить инфраструктуру на другие проекты монорепозитория, это отдельная задача с собственным Stage 1 (discovery) для каждого — не расширение этого ADR задним числом.
