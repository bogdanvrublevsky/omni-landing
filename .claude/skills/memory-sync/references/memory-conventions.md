# Структура тематического документа в .claude/memory/

Каждый файл (кроме `MEMORY.md`) содержит три раздела, в этом порядке:

1. **Описание** — 1-3 предложения, что это за область и почему у неё отдельный документ.
2. **Принятые решения (и факты)** — конкретика, с датами там, где это важно (например, инциденты). Не дублирует `CLAUDE.md` дословно — там политика/правило, здесь — история и нюансы, которые к этому правилу привели.
3. **Связанные документы** — markdown-ссылки на другие файлы `.claude/memory/`, `docs/adr/`, `CLAUDE.md`. Реальные относительные пути, не текст без ссылки.

## Когда заводить новый файл, а не дописывать существующий

Новый файл — когда появляется тема, которая: (а) не покрывается ни одним существующим файлом по смыслу, и (б) будет пополняться дальше (не разовый факт). Разовый факт без развития — просто допиши в подходящий существующий файл.

## Пример

См. `.claude/memory/security.md` — образцовая структура: описание модели безопасности + задокументированный реальный инцидент с датой, действием и остаточным риском.
