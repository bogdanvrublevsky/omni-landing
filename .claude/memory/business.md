# Business

## Описание

anltx — продающая контентная платформа для монетизации аналитической экспертности автора. Не курс, не датасет, не инструмент "сам по себе" — предмет продажи это экспертность и опыт, то есть то, что нельзя бесплатно получить в другом месте.

## Принятые решения

- **Бизнес-модель:** freemium. Бесплатный контент (блог, раздел полезностей) наращивает авторитет и трафик → конвертируется в платные консультации и внедрение аналитики.
- **Целевая аудитория (ICP):** начинающие веб-аналитики, дата-аналитики, системные аналитики, дата-инженеры.
- **Ценностное предложение:** конкурентное отличие не в информации (она доступна бесплатно везде), а в экспертности и практическом опыте автора.
- **MVP:** посадочная страница об экспертизе/услугах + структура для блога и раздела полезностей.
- **Долгосрочное направление:** README репозитория описывает более широкое видение — `lwtms.anltx.xyz` (light-weight tag management system) и `sstms.anltx.xyz` (server-side TMS) как конкретное содержание "полноценной аналитической платформы", упомянутой при обсуждении дальнейшего развития. На момент бутстрапа инфраструктуры (2026-07) кода для них ещё нет — только README. Эти направления **вне скоупа** текущей инфраструктуры (main/), см. [[roadmap]].
- **Кастомная CMS:** будет разрабатываться в рамках этого же проекта, но не входит в MVP. Архитектура ещё не определена, см. `docs/adr/0004-custom-cms-direction.md`.
