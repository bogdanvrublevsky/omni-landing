# Security

## Описание

Модель безопасности для `main/` и связанной инфраструктуры (Cloudflare Worker, аналитика). Репозиторий `bogdanvrublevsky/anltx.xyz` — публичный.

## Принятые решения

- Секреты (токены, пароли, ключи) никогда не коммитятся. Гейт — pre-commit secrets-scan hook (см. `.claude/hooks/`).
- Токен Telegram-бота для Cloudflare Worker хранится только в Wrangler secrets; локальный файл `.dev.vars` — в `.gitignore`, не коммитится.
- Cookie consent banner обязателен и должен гейтить загрузку GTM/GA4 до согласия пользователя (GDPR/ePrivacy — аудитория двуязычная, EN/RU).
- `<head>` (meta-теги, GTM/GA4-сниппеты, CSP) не изменяется Claude автономно — только по явному подтверждению пользователя.

## Инцидент (закрыт)

- **Дата обнаружения:** при клонировании репозитория для бутстрапа инфраструктуры (2026-07-21).
- **Что произошло:** в `ttapp/data/users.json` был закоммичен пароль администратора (`bogdan_admin`) в открытом виде в публичный репозиторий; `ttapp/auth.js` сравнивал его как plaintext-строку.
- **Действие:** значение пароля заменено на плейсхолдер `ROTATED_SET_VIA_ENV_BEFORE_USE` в HEAD ветки `main`, коммит `29e32e3`, запушено в `origin/main` напрямую (репозиторий уже был публичным, откладывать было нецелесообразно).
- **Остаточный риск:** старое значение пароля остаётся в истории git (коммит `88009e6` и ранее). Полная зачистка истории (`git filter-repo`/BFG + force-push) не выполнялась — деструктивная операция, требует отдельного явного запроса пользователя. Если пароль `admin1234` использовался где-либо ещё за пределами этого проекта — рекомендовано сменить его там.
- **Скоуп:** `ttapp/` вне зоны ответственности текущей инфраструктуры; построение нормальной модели секретов для него — отдельная будущая задача, не часть этого бутстрапа.
